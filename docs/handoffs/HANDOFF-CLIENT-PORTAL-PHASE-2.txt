7. LIMITASI & REKOMENDASI PHASE 3 (CLIENT BOOKING & AVAILABILITY)
-----------------------------------------------------------------
Limitasi saat ini:
- Lima halaman portal masih berupa UI shell & contextual placeholder tanpa
  sinkronisasi jadwal booking, submission reservasi, atau billing ledger.
- Verifikasi viewport fisik 320px–1440px di browser Chromium/headless belum
  dijalankan langsung pada fase ini (struktur responsive divalidasi melalui
  parity kelas Admin Shell dan unit/integration test JSDOM).

Rekomendasi Phase 3 (Client Booking & Availability):
1. Proyeksi jadwal ketersediaan room studio (read-only / real-time availability
   projection) untuk halaman `Book a Session` (/portal/book).
2. Integrasi alur pengajuan permintaan booking langsung oleh Client terautentikasi
   tanpa membocorkan data internal booking pelanggan lain (`clientBookings`
   atau client-safe request projection dengan Firestore Security Rules ketat).
3. Penampilan daftar permintaan & sesi Client pada `My Bookings` (/portal/bookings)
   dan ringkasan "Next Session" / "Account Snapshot" pada `Overview` (/portal).
