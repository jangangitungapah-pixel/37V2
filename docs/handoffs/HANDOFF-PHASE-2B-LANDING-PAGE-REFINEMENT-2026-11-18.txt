3. COMPLETED REPAIRS (PRIORITIES 1–10)
============================================================

Priority 1 & Priority 10 — HTML Metadata & SEO (`index.html`):
- Fixed broken `<meta name="description" ... />` element where the tag name
  was missing, leaving a standalone `content` attribute in `<head>`.
- Removed `<meta property="og:image" content="/images/demo/room-a-live.svg" />`
  so an illustrative demo SVG is not advertised as production studio photography.
- Preserved valid `<html lang="en">`, `<meta name="theme-color" content="#F1EEE4" />`,
  `<title>`, Open Graph `og:type`, `og:title`, `og:description`, and ensured
  copy makes no unverified facility claims, canonical domain, or fake
  LocalBusiness structured data.

Priority 2 — Booking Form Improvements (`BookingSection.jsx`, `bookingInquirySchema.js`, `src/lib/booking-date.js`):
- Replaced the hardcoded `'2026-11-21'` default date with `getTodayLocalDateString()`
  powered by `date-fns` (`format(now, 'yyyy-MM-dd')`) without UTC `.toISOString()` drift.
- Set HTML `<input type="date" min={todayDate}>` from the same helper and
  refreshed `todayDate` on date focus and inquiry reset.
- Extended Zod validation in `bookingInquirySchema.js` to validate:
  required date, `YYYY-MM-DD` format, strict calendar validity (e.g., rejects
  `2026-02-30`), and not-in-past check evaluated dynamically against `new Date()`
  at submission time (catching midnight rollovers when the tab stays open).
- Replaced single-line `<input>` for Notes with a multiline `<textarea rows={3}>`
  (`min-h-24`), live `{notesLength} / 400` character counter (`aria-describedby`),
  and preserved Zod max-400 validation.
- Fixed service/room preselection synchronization using `selectionVersion` so
  re-selecting a service or room after manual toggles always updates form state.
- Removed unconfirmed `"WIB"` timezone suffix from time options and improved
  error message contrast (`--studio-error-ink: #b92b0c`).

Priority 3 — Business Claims & Demo Content Audit (`src/data/landing-page-content.js`, `HeroSection.jsx`, `TestimonialsAndContactSection.jsx`):
- Audited and removed/neutralized unverified factual claims across all sections:
  - Removed invented specs (`42m²`, `24ch`, `15min setup turnaround`, room
    capacities `6–7 musicians` / `1–4 people`, invented equipment/amenities
    lists, unconfirmed `10:00 – 23:00` schedule, and `"2 min from the mainline"`).
  - Replaced `"BAND FAVORITE"` with neutral `"GROUP SESSION"`.
  - Replaced `"SOUNDPROOFED & ACOUSTICALLY TREATED"`, `"BACKLINE INCLUDED"`,
    `"TREATED ROOMS"`, and `"ON-SITE CREW SUPPORT"` with neutral preview labels.
  - Replaced 5-star rating icons and fabricated review copy with explicitly
    labeled `UNVERIFIED` / `DEMO PLACEHOLDER` layout slots.
  - Changed hero photo tag from `"DEMO PHOTO"` to `"DEMO ASSET"` and clarified
    all demo SVG illustrations as illustrative placeholders awaiting real photos.

Priority 4 — Contact & External Link Behavior (`src/lib/external-links.js`, `TestimonialsAndContactSection.jsx`, `SiteFooter.jsx`, `landing-page-content.js`):
- Added explicit configurable destination fields: `mapsUrl`, `whatsappUrl`,
  `whatsappNumber`, `prefilledMessage`, and `socialLinks[].href`.
- Added defensive validators (`isValidHttpUrl`, `resolveMapsHref`,
  `resolveWhatsAppHref`, `resolveSocialHref`) so external anchors render ONLY
  when BOTH the confirmation flag (`isAddressConfirmed` / `isConfirmed`) AND a
  valid `http(s)` URL are present (blocking empty strings, pending tokens, or
  invalid protocols like `javascript:`).
- Confirmed links open safely with `target="_blank" rel="noopener noreferrer"`;
  unconfirmed items preserve honest pending notices and inquiry-form fallback.
