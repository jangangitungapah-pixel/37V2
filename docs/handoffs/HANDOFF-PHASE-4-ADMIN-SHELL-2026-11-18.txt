3. ADMIN SHELL ARCHITECTURE
============================================================

The Phase 4 Admin Shell wraps all `/admin/*` routes inside `<RequireStaff>` and
`<AdminLayout />`:
- `AdminLayout`: Manages desktop sidebar collapse state (`isSidebarCollapsed`,
  defaulting to `false` / expanded) and mobile off-canvas drawer state
  (`isMobileDrawerOpen`), resolves the active navigation item from the current
  pathname, and renders `<Outlet />` with a restrained Motion entrance
  transition (`opacity` + `6px` vertical offset, `180ms`, respecting
  `prefers-reduced-motion: reduce`).
- `AdminSidebar`: Persistent desktop (`1024px+`) vertical navigation rail in
  ink-black (`#151515`) with acid-lime (`#C8F13A`) active surface and
  signal-orange (`#FF4B22`) left accent bar.
- `AdminTopbar`: Sticky header (`min-h-16 sm:min-h-[72px]`) displaying mobile
  drawer trigger, desktop sidebar toggle, dynamic breadcrumb
  (`37 Studio / <Module Label>`), dynamic `<h1>` page title, authenticated user
  initials avatar + `displayName` + `email` + `OWNER`/`STAFF` role badge,
  public website shortcut, and functional `Sign Out` button.

============================================================
4. SIDEBAR EXPAND/COLLAPSE & MOBILE DRAWER BEHAVIOR
============================================================

- Desktop Expanded State (`272px` wide): Displays square `37` mark,
  `37 MUSIC STUDIO` wordmark, `STUDIO MANAGEMENT` subtitle, collapse button
  (`aria-expanded="true"`), all eight navigation items with icons, labels, and
  order numbers (`01`–`08`), and bottom workspace descriptor.
- Desktop Collapsed State (`80px` wide): Transitions smoothly via `motion/react`
  (`220ms`, or `0ms` when reduced-motion is active). Text labels are removed
  while icons remain stationary and centered. Every icon link retains its
  accessible `aria-label` and displays a tooltip badge on hover or focus.
- Mobile & Tablet Drawer (`<1024px`): Uses `@base-ui/react/dialog` to render an
  accessible off-canvas left drawer (`280px` wide, `max-w-[86vw]`) with dimmed
  backdrop. Selecting any navigation item, clicking the backdrop, clicking the
  close button, or pressing `Escape` closes the drawer and returns focus to the
  topbar menu trigger.
