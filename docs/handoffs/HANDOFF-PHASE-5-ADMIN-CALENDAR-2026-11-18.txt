4. FIRESTORE DATA MODEL
============================================================

1. `bookings/{bookingId}`:
   Canonical booking record storing customer snapshot (`customerName`, `phone`, `bandName`), schedule (`studioId`, `date`, `startMinute`, `durationMinutes`, `endMinute`, `timeZone: 'Asia/Jakarta'`), service & pricing snapshot (`serviceId`, `serviceLabel`, `packageId`, `packageLabel`, `recordingTypeId`, `recordingTypeLabel`, `unitRate`, `subtotal`, `discountAmount`, `totalAmount`), initial payment snapshot (`initialPaymentStatus`, `initialPaidAmount`, `paymentMethod`), session lifecycle (`sessionStatus`, `checkedInAt`, `checkedInByUid`, `actualStartedAt`, `actualCompletedAt`), and audit/concurrency metadata (`createdAt`, `createdByUid`, `updatedAt`, `updatedByUid`, `version`).
2. `bookingSlots/{date__studioId__slotStartMinute}`:
   Deterministic 30-minute slot lock document containing only `{ bookingId, date, studioId, slotStartMinute, createdAt }` (no customer PII).
3. `bookingEvents/{eventId}`:
   Immutable append-only activity log containing `{ bookingId, eventType, actorUid, createdAt, previousValue, newValue, note }`.

============================================================
6. TRANSACTION & SLOT LOCKING BEHAVIOR
============================================================

- All write operations (`createBooking`, `updateOrRescheduleBooking`, `cancelBooking`, `transitionBookingSession`) run inside `runTransaction` with all reads executed before any writes.
- Every booking acquires deterministic 30-minute locks (`bookingSlots/{date__studioId__slotStartMinute}`).
- Rescheduling reads both old and target slot locks, aborts atomically if any target slot is locked by another booking, releases unused old locks, and acquires new locks.
- Cancelling or marking No Show releases all owned `bookingSlots` locks while preserving the `bookings/{bookingId}` document.
- Pre-generated `bookingId` and `eventId` (UUID) guarantee idempotency across retries, and `version` checks reject stale updates (`booking/stale-update`).
